# Decisions

Spec gaps and deviations found while implementing [`design.md`](design.md). Add one row per decision, in the
same PR as the task that hit it. Never edit `design.md` in a feature PR.

| 2026-10-23 | T00 | The tracked guide was `agents.md`; T00 wants `AGENTS.md`. | Renamed with `git mv`; §0 content merged into the existing guide. | Keep the existing rules and one source of truth. |

| 2026-10-23 | T00 | `docs/design.md` and `docs/tasks.md` failed rumdl. | Accepted rumdl's autofixes (blank lines before lists, code fence languages) and wrapped one long line. | Content is unchanged; prek must pass. |
| 2026-10-23 | T01 | The Rust toolchain pin must be an exact stable release; which one? | `1.99.1`, the installed stable. | Design §5 requires an exact pin of at least 1.85. |
| 2026-10-23 | T01 | Bare `cargo test` picks the system python (3.9), which fails `abi3-py314`. | `.cargo/config.toml` sets `PYO3_PYTHON` to the uv venv interpreter (relative). | Acceptance requires plain `cargo test --workspace` to pass; T04 CI must run `uv sync` first. |
| 2026-10-23 | T01 | The prek `cargo-clippy` hook sets `PYO3_NO_PYTHON=1` and only watches `src/**/*.rs`. | Hook edited with permission: dropped the env var and widened the path filter to `crates/`. | 2026-10-23 | T01 | `maturin` is needed for `uv run maturin build`. | Added `maturin` to the dev dependency group. | The acceptance check runs it through uv. |
| 2026-10-23 | T02 | Task asks for pyright, mypy and `tests/test_errors.py`, `asyncio_mode="auto"`. | Only `ty` (via prek); tests in `src/rowx/__tests__/unit/`; added `db` and `timing` markers; skipped `asyncio_mode` and pytest-asyncio. | AGENTS.md mandates `ty` and the `__tests__` layout; no async tests exist yet, so the plugin lands with the first one. |
| 2026-10-23 | T02 | `DatabaseError` must keep five attributes and stay picklable. | Overrode `__reduce__` and `__str__` (`sqlstate: message`). | Default `BaseException` pickling would drop attributes with a custom `__init__` signature. |
| 2026-10-23 | T05 | The acceptance check says "every array row has an element", but design §6 defines one generic `array` row with no element field. | One `ArrayKind` row (accepts `list`, `tuple`); the test asserts exactly one such row. | 2026-10-23 | T05 | How do `Matcher`, `TzRule`, `Codec` and `Format` cross into Python? | The pyclass exposes strings: `matcher` plus `matcher_oid`/`matcher_name`, `tz`, `decode`/`encode` (`"unsupported"` for now) and `encode_format`. | Frozen pyclass with plain fields; codec tasks only add names. |
| 2026-10-23 | T05 | `domain` has no metadata of its own, and `json`/`jsonb` results depend on the annotation (§9.5). | `domain` has an empty `py_result` and `accepted_params`; `json`/`jsonb` use `object`. | Domains resolve to their base type. |
| 2026-10-23 | T05 | Acceptance asks for `pyright` on `_core.pyi`. | Checked through `ty` in prek instead. | AGENTS.md mandates `ty`; see the T02 row. |
| 2026-10-23 | T07 | Task puts tests in `tests/runtime/test_connect.py`; AGENTS.md puts them under `src/rowx/__tests__/`. | Tests are in `src/rowx/__tests__/integration/runtime/test_connect.py`, use `asyncio.run` (no pytest-asyncio yet), and reuse the `schema` fixture through a `__tests__/conftest.py` re-export plus `pythonpath = ["."]` in the pytest config. | AGENTS.md layout wins; the fixture stays in one place. |
| 2026-10-23 | T07 | `_core.pyi` listed `__aenter__`/`__aexit__` on `Connection`; the task puts them on the Python wrapper. | Removed from the stub; the Rust class has `close`, `closed` and `statement_cache_size`. | One owner for the context-manager protocol. |
| 2026-10-23 | T07 | How is `connect_timeout` enforced, and what does a bad value do? | `tokio::time::timeout` around the connect, giving `InterfaceError("connection timed out")`; a negative or NaN value raises `InterfaceError` synchronously. | The driver crate keeps its `connect(dsn, handle)` signature. |
| 2026-10-23 | T07 | tokio needs `time` and `sync` features. | Added both to the workspace `tokio` dependency. | Timeout and the shared connection mutex. |
| 2026-10-23 | T08 | Task puts tests in `tests/runtime/test_fetch_core.py` and calls `c._fetch` on the connection; the Python wrapper has no `_fetch`. | Tests are in `src/rowx/__tests__/integration/runtime/test_fetch_core.py` and call `conn._impl._fetch`; `_query.py` is untouched. | AGENTS.md layout wins (see T07); T11 owns the wrapper's fetch methods. |
| 2026-10-23 | T08 | `Raw<'a>` in design §7.3 carries `&Type`, but `FromSql` gives `ty` a lifetime unrelated to `'a`. | `Raw<'a>(Option<&'a [u8]>)`; the type comes from `row.columns()[i].type_()`. Rows are kept as `tokio_postgres::Row` (Send) instead of `Vec<Option<Bytes>>`. | Avoids copying every cell; NULL mask is still applied while streaming. |
| 2026-10-23 | T08 | Where do the `ConnectionBusyError`, `RowShapeError` and `DecodeError` mappings live, and what is the mask polarity? | `Error::{Busy,RowShape,Decode}` in `rowx-pg`, mapped in `errors.rs`. `mask[i] == True` means nullable; a mask or scalar shape that disagrees with the column count raises `RowShapeError`. | Matches §3.7 and the acceptance cases (`[False, False]` rejects NULL). |
| 2026-10-23 | T08 | Cancelling the Python future drops the claim, so the state goes Busy → Idle with no settle step. | Accepted for now; `Settling` and the server-side cancel land with T22/T23. | T08 scopes state to Idle/Busy/Closed. |
| 2026-10-23 | T08 | `rowx-py` needs `Row`/`Type` from tokio-postgres, and `rowx-pg` needs `futures-util` for `RowStream`. | `rowx-pg` re-exports `Row` and `Type` and gains a `futures-util` dependency (no default features). | Keeps tokio-postgres out of `rowx-py`'s dependency list. |
| 2026-10-23 | T09 | Task puts tests in `tests/unit/test_template.py`; AGENTS.md puts them under `src/rowx/__tests__/`. | Tests are in `src/rowx/__tests__/unit/test_template.py`. | AGENTS.md layout wins (see T07). |
| 2026-10-23 | T09 | How do `segments` treat `:ident` output and the adjacency spaces? | `segments` cover only parameter boundaries (`len == n_params + 1`); quoted identifiers are part of the static text, and an inserted space belongs to the segment next to its text, not to the `$n` placeholder. | Keeps the `len` invariant from §3.5 and leaves `placeholders` as exactly `$n`. |
| 2026-10-23 | T10 | Task puts the table and tests under `tests/`; AGENTS.md puts tests under `src/rowx/__tests__/`. | 2026-10-23 | T11 | Task puts tests in `tests/runtime/test_query_slice.py`; AGENTS.md puts them under `src/rowx/__tests__/`. | Tests are in `src/rowx/__tests__/integration/runtime/test_query_slice.py`.
